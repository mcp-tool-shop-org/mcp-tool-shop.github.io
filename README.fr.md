Outils d'IA pour les développeurs — conçus pour fonctionner localement, sans nécessiter de cloud.

MCP Tool Shop crée des outils open source qui s'intègrent aux agents d'IA via le [Model Context Protocol](https://modelcontextprotocol.io/). Chaque outil fonctionne sur votre machine, utilise votre GPU et respecte votre vie privée.

## Ce qu'il y a à l'intérieur

| Outil | Fonctionnalités |
| ------ | ------------- |
| [File Compass](https://github.com/mcp-tool-shop-org/file-compass) | Serveur MCP pour la recherche et la navigation intelligentes de fichiers. |
| [Tool Compass](https://github.com/mcp-tool-shop-org/tool-compass) | Routage intelligent des outils pour les flux de travail des agents MCP. |
| [Brain-Dev](https://github.com/mcp-tool-shop-org/brain-dev) | Couche de mémoire persistante pour les agents de codage IA. |
| [Voice Soundboard](https://github.com/mcp-tool-shop-org/voice-soundboard) | Effets vocaux en temps réel et tableau de sons pour les diffusions. |
| [Comfy-Headless](https://github.com/mcp-tool-shop-org/comfy-headless) | Exécuteur ComfyUI sans interface graphique pour la génération automatisée d'images. |
| [Polyglot MCP](https://github.com/mcp-tool-shop-org/polyglot-mcp) | Serveur de traduction local alimenté par TranslateGemma + Ollama. |
| [Context Window Manager](https://github.com/mcp-tool-shop-org/context-window-manager) | Suivi du budget de jetons pour les conversations LLM. |

## Technologies utilisées

Python · TypeScript · C# · .NET MAUI · WinUI 3 · MCP · Ollama · CUDA

Tout fonctionne localement. Aucune dépendance cloud, aucune clé API requise pour les fonctionnalités principales.
