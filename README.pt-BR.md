Ferramentas de IA para desenvolvedores — criadas para serem executadas localmente, sem necessidade de nuvem.

A MCP Tool Shop desenvolve ferramentas de código aberto que se integram com agentes de IA através do [Model Context Protocol](https://modelcontextprotocol.io/). Cada ferramenta é executada na sua máquina, utiliza a sua GPU e respeita a sua privacidade.

## O que está incluído

| Ferramenta | O que ela faz |
| ------ | ------------- |
| [File Compass](https://github.com/mcp-tool-shop-org/file-compass) | Servidor MCP para pesquisa e navegação inteligente de arquivos. |
| [Tool Compass](https://github.com/mcp-tool-shop-org/tool-compass) | Roteamento inteligente de ferramentas para fluxos de trabalho de agentes MCP. |
| [Brain-Dev](https://github.com/mcp-tool-shop-org/brain-dev) | Camada de memória persistente para agentes de codificação de IA. |
| [Voice Soundboard](https://github.com/mcp-tool-shop-org/voice-soundboard) | Efeitos de voz em tempo real e painel de som para transmissões. |
| [Comfy-Headless](https://github.com/mcp-tool-shop-org/comfy-headless) | Executador ComfyUI sem interface gráfica para geração automatizada de imagens. |
| [Polyglot MCP](https://github.com/mcp-tool-shop-org/polyglot-mcp) | Servidor de tradução local alimentado por TranslateGemma + Ollama. |
| [Context Window Manager](https://github.com/mcp-tool-shop-org/context-window-manager) | Rastreamento do orçamento de tokens para conversas de LLM. |

## Tecnologias

Python · TypeScript · C# · .NET MAUI · WinUI 3 · MCP · Ollama · CUDA

Tudo é executado localmente. Sem dependências de nuvem, sem chaves de API para as funcionalidades principais.
