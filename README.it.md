Strumenti di intelligenza artificiale per sviluppatori, progettati per funzionare localmente, senza la necessità di servizi cloud.

MCP Tool Shop sviluppa strumenti open source che si integrano con agenti di intelligenza artificiale tramite il [Model Context Protocol](https://modelcontextprotocol.io/). Ogni strumento viene eseguito sulla vostra macchina, utilizza la vostra GPU e rispetta la vostra privacy.

## Cosa è incluso

| Strumento | Funzionalità |
| ------ | ------------- |
| [File Compass](https://github.com/mcp-tool-shop-org/file-compass) | Server MCP per la ricerca e la navigazione intelligente dei file. |
| [Tool Compass](https://github.com/mcp-tool-shop-org/tool-compass) | Instradamento intelligente degli strumenti per i flussi di lavoro degli agenti MCP. |
| [Brain-Dev](https://github.com/mcp-tool-shop-org/brain-dev) | Livello di memoria persistente per gli agenti di codifica AI. |
| [Voice Soundboard](https://github.com/mcp-tool-shop-org/voice-soundboard) | Effetti vocali in tempo reale e soundboard per le trasmissioni. |
| [Comfy-Headless](https://github.com/mcp-tool-shop-org/comfy-headless) | Esecutore ComfyUI senza interfaccia grafica per la generazione automatica di immagini. |
| [Polyglot MCP](https://github.com/mcp-tool-shop-org/polyglot-mcp) | Server di traduzione locale basato su TranslateGemma + Ollama. |
| [Context Window Manager](https://github.com/mcp-tool-shop-org/context-window-manager) | Monitoraggio del budget di token per le conversazioni con i modelli linguistici di grandi dimensioni (LLM). |

## Tecnologie utilizzate

Python · TypeScript · C# · .NET MAUI · WinUI 3 · MCP · Ollama · CUDA

Tutto viene eseguito localmente. Nessuna dipendenza dal cloud, nessuna chiave API per le funzionalità principali.
