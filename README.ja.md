開発者向けのAIツール。ローカルで動作し、クラウドは不要です。

MCP Tool Shopは、[Model Context Protocol](https://modelcontextprotocol.io/)を通じてAIエージェントと連携するオープンソースツールを開発しています。すべてのツールは、お客様のコンピューター上で動作し、GPUを活用し、お客様のプライバシーを尊重します。

## 内容

| ツール | 機能 |
| ------ | ------------- |
| [File Compass](https://github.com/mcp-tool-shop-org/file-compass) | インテリジェントなファイル検索およびナビゲーションのためのMCPサーバー |
| [Tool Compass](https://github.com/mcp-tool-shop-org/tool-compass) | MCPエージェントワークフローのためのスマートなツールルーティング |
| [Brain-Dev](https://github.com/mcp-tool-shop-org/brain-dev) | AIコーディングエージェントのための永続メモリレイヤー |
| [Voice Soundboard](https://github.com/mcp-tool-shop-org/voice-soundboard) | ストリーミングのためのリアルタイム音声エフェクトおよびサウンドボード |
| [Comfy-Headless](https://github.com/mcp-tool-shop-org/comfy-headless) | 自動画像生成のためのヘッドレスComfyUIランナー |
| [Polyglot MCP](https://github.com/mcp-tool-shop-org/polyglot-mcp) | TranslateGemma + Ollamaを搭載したローカル翻訳サーバー |
| [Context Window Manager](https://github.com/mcp-tool-shop-org/context-window-manager) | LLM会話のためのトークン予算追跡機能 |

## 使用技術

Python、TypeScript、C#、.NET MAUI、WinUI 3、MCP、Ollama、CUDA

すべてがローカルで動作します。コア機能にはクラウド依存やAPIキーは不要です。
