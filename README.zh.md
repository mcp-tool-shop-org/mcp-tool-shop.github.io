为开发者提供的 AI 工具——构建于本地运行，无需云服务。

MCP Tool Shop 构建开源工具，这些工具通过 [模型上下文协议](https://modelcontextprotocol.io/) 与 AI 代理集成。 每个工具都在您的机器上运行，利用您的 GPU，并尊重您的隐私。

## 内容

| 工具 | 功能 |
| ------ | ------------- |
| [File Compass](https://github.com/mcp-tool-shop-org/file-compass) | 用于智能文件搜索和导航的 MCP 服务器 |
| [Tool Compass](https://github.com/mcp-tool-shop-org/tool-compass) | 用于 MCP 代理工作流程的智能工具路由 |
| [Brain-Dev](https://github.com/mcp-tool-shop-org/brain-dev) | 用于 AI 编码代理的持久内存层 |
| [Voice Soundboard](https://github.com/mcp-tool-shop-org/voice-soundboard) | 用于直播的实时语音效果和音效面板 |
| [Comfy-Headless](https://github.com/mcp-tool-shop-org/comfy-headless) | 无头 ComfyUI 运行器，用于自动化图像生成 |
| [Polyglot MCP](https://github.com/mcp-tool-shop-org/polyglot-mcp) | 由 TranslateGemma + Ollama 驱动的本地翻译服务器 |
| [Context Window Manager](https://github.com/mcp-tool-shop-org/context-window-manager) | 用于 LLM 对话的令牌预算跟踪 |

## 技术栈

Python · TypeScript · C# · .NET MAUI · WinUI 3 · MCP · Ollama · CUDA

所有内容都运行在本地。 没有云依赖，核心功能无需 API 密钥。
