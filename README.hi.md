एआई उपकरण डेवलपर्स के लिए - स्थानीय रूप से चलाने के लिए डिज़ाइन किए गए, किसी क्लाउड की आवश्यकता नहीं।

MCP टूल शॉप, ओपन-सोर्स उपकरण बनाती है जो [मॉडल कॉन्टेक्स्ट प्रोटोकॉल](https://modelcontextprotocol.io/) के माध्यम से एआई एजेंटों के साथ एकीकृत होते हैं। प्रत्येक उपकरण आपके मशीन पर चलता है, आपके जीपीयू के साथ काम करता है, और आपकी गोपनीयता का सम्मान करता है।

## इसमें क्या है

| उपकरण | यह क्या करता है |
| ------ | ------------- |
| [File Compass](https://github.com/mcp-tool-shop-org/file-compass) | बुद्धिमान फ़ाइल खोज और नेविगेशन के लिए एमसीपी सर्वर |
| [Tool Compass](https://github.com/mcp-tool-shop-org/tool-compass) | एमसीपी एजेंट वर्कफ़्लो के लिए स्मार्ट टूल रूटिंग |
| [Brain-Dev](https://github.com/mcp-tool-shop-org/brain-dev) | एआई कोडिंग एजेंटों के लिए स्थायी मेमोरी लेयर |
| [Voice Soundboard](https://github.com/mcp-tool-shop-org/voice-soundboard) | लाइव स्ट्रीम के लिए रीयल-टाइम वॉयस इफेक्ट्स और साउंडबोर्ड |
| [Comfy-Headless](https://github.com/mcp-tool-shop-org/comfy-headless) | स्वचालित छवि निर्माण के लिए हेडलेस कॉमफीयूआई रनर |
| [Polyglot MCP](https://github.com/mcp-tool-shop-org/polyglot-mcp) | ट्रांसलेटजेमा + ओलमा द्वारा संचालित स्थानीय अनुवाद सर्वर |
| [Context Window Manager](https://github.com/mcp-tool-shop-org/context-window-manager) | एलएलएम वार्तालापों के लिए टोकन बजट ट्रैकिंग |

## तकनीकें

पायथन · टाइपस्क्रिप्ट · सी# · .NET MAUI · विनयूआई 3 · एमसीपी · ओलमा · CUDA

सब कुछ स्थानीय रूप से चलता है। किसी भी मुख्य कार्यक्षमता के लिए क्लाउड निर्भरता या एपीआई कुंजियों की आवश्यकता नहीं है।
