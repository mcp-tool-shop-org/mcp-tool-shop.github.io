Herramientas de IA para desarrolladores: diseñadas para funcionar localmente, sin necesidad de la nube.

MCP Tool Shop crea herramientas de código abierto que se integran con agentes de IA a través del [Protocolo de Contexto del Modelo](https://modelcontextprotocol.io/). Cada herramienta se ejecuta en su máquina, funciona con su GPU y respeta su privacidad.

## ¿Qué incluye?

| Herramienta | Función |
| ------ | ------------- |
| [File Compass](https://github.com/mcp-tool-shop-org/file-compass) | Servidor MCP para búsqueda y navegación inteligente de archivos. |
| [Tool Compass](https://github.com/mcp-tool-shop-org/tool-compass) | Enrutamiento inteligente para flujos de trabajo de agentes MCP. |
| [Brain-Dev](https://github.com/mcp-tool-shop-org/brain-dev) | Capa de memoria persistente para agentes de codificación de IA. |
| [Voice Soundboard](https://github.com/mcp-tool-shop-org/voice-soundboard) | Efectos de voz en tiempo real y panel de sonido para transmisiones. |
| [Comfy-Headless](https://github.com/mcp-tool-shop-org/comfy-headless) | Ejecutor headless de ComfyUI para generación automatizada de imágenes. |
| [Polyglot MCP](https://github.com/mcp-tool-shop-org/polyglot-mcp) | Servidor de traducción local impulsado por TranslateGemma + Ollama. |
| [Context Window Manager](https://github.com/mcp-tool-shop-org/context-window-manager) | Seguimiento del presupuesto de tokens para conversaciones de LLM. |

## Tecnologías utilizadas

Python · TypeScript · C# · .NET MAUI · WinUI 3 · MCP · Ollama · CUDA

Todo se ejecuta localmente. Sin dependencias de la nube, sin claves de API para la funcionalidad principal.
