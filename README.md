AI tools for developers — built to run locally, no cloud required.

MCP Tool Shop builds open-source tools that integrate with AI agents through the [Model Context Protocol](https://modelcontextprotocol.io/). Every tool runs on your machine, works with your GPU, and respects your privacy.

## What's Inside

| Tool | What it does |
|------|-------------|
| [File Compass](https://github.com/mcp-tool-shop-org/file-compass) | MCP server for intelligent file search and navigation |
| [Tool Compass](https://github.com/mcp-tool-shop-org/tool-compass) | Smart tool routing for MCP agent workflows |
| [Brain-Dev](https://github.com/mcp-tool-shop-org/brain-dev) | Persistent memory layer for AI coding agents |
| [Voice Soundboard](https://github.com/mcp-tool-shop-org/voice-soundboard) | Real-time voice effects and soundboard for streams |
| [Comfy-Headless](https://github.com/mcp-tool-shop-org/comfy-headless) | Headless ComfyUI runner for automated image generation |
| [Polyglot MCP](https://github.com/mcp-tool-shop-org/polyglot-mcp) | Local translation server powered by TranslateGemma + Ollama |
| [Context Window Manager](https://github.com/mcp-tool-shop-org/context-window-manager) | Token budget tracking for LLM conversations |

## Stack

Python · TypeScript · C# · .NET MAUI · WinUI 3 · MCP · Ollama · CUDA

Everything runs locally. No cloud dependencies, no API keys for core functionality.
